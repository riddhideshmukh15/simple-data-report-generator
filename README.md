# Simple Data Report Generator

A beginner-friendly Python project that takes multiple numerical values from the user and generates a simple data report.

## Features

* Enter multiple values
* Calculate the total
* Calculate the average
* Find the highest value
* Find the lowest value
* Count the number of values

## How It Works

1. Enter how many values you want to add.
2. Enter each value one by one.
3. The program stores the values in a list.
4. It calculates the total, average, highest, and lowest values.
5. It displays the final data report.

## Example

```text
==== SIMPLE DATA REPORT GENERATOR ====

How many values do you want to enter? 5
Enter value: 10
Enter value: 20
Enter value: 30
Enter value: 40
Enter value: 50

=== DATA REPORT ===

Total: 150.0
Average: 30.0
Highest: 50.0
Lowest: 10.0
Number of values: 5
```

## Technologies Used

* Python

Make sure Python is installed on your computer.

```bash
python data_report_generator.py
```
