# 📊 Simple Data Report Generator

A beginner-friendly Python project that takes numerical values from the user and generates a simple data report with useful statistics.

## ✨ Features

* Enter multiple numerical values
* Calculate the **total**
* Calculate the **average**
* Find the **highest value**
* Find the **lowest value**
* Calculate the **range**
* Count positive and negative values
* Count even and odd values
* Calculate the percentage of values above average
* Display all entered values

## 🛠️ Technologies Used

* Python 3

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in Command Prompt or VS Code.
4. Run:

```bash
python simple_data_report.py
```
